All-in

About $2,000–2,200 a month per tenant, held warm. List prices; committed-use terms on any cloud cut the GPU line.

The same shape elsewhere

  • Azure · NC H100 v5 — AKS node pool or a single GPU VM in the customer's subscription; same containers, same weights-volume pattern (Blob + blobfuse).
  • AWS · p5 / g6e class — EKS or a single GPU instance in an account the customer owns; IAM + KMS, private VPC egress only.
  • Google Cloud · A3 (H100) — GKE with an A3 node or a single GPU VM; Workload Identity, VPC Service Controls.

Notes

  • Flat per-tenant rate, not per-token metering: the GPU line dominates and everything else is under $200.
  • Capacity is peak concurrent sessions, not head count: one H100 sustains 8–12 concurrent streaming chats at FP8 with first tokens in 1–2 s.

04Run it

# Card 0 CUDA_VISIBLE_DEVICES=0 python -m sglang.launch_server --model-path google/gemma-4-31b-it --quantization fp8 --tp 1 --context-length 262144 --tool-call-parser gemma4 --reasoning-parser gemma4 --port 30000 --mem-fraction-static 0.90 # Card 1 ComfyUI :8188 · voice :8001 · text-embeddings-router :8080 · optional 7–8B at 4-bit on its own port
  • Both cards flat out: Pro 6000 600 W + A6000 300 W + platform ~200 W ≈ 1.1 kW, about 9 A at 120 V. Fine on a 15 A circuit; a dedicated 20 A circuit leaves room for a second A6000.
  • Ubuntu 24.04 Desktop: amdgpu drives the display card and Wayland; NVIDIA R570+ / CUDA 12.8+ (sm_120) runs compute headless. Serve from containers and hold driver updates before demo days.
  • One process per card, each pinned with CUDA_VISIBLE_DEVICES, behind one OpenAI-compatible front door. The flagship never reloads; the utility card hosts image, voice, embeddings and a small LLM.
  • Run the OpenClaw gateway and the Portal on the same box for a fully local demo, or point a separate control machine at its endpoint; both work.
